about=CyanSkin gives QGIS a ribbon interface, for users moving to QGIS from other desktop GIS software with a ribbon (such as ArcGIS Pro), for training rooms and for organisations moving to QGIS. It adds a ribbon (Map, Insert, Analysis, View, Edit, Share, Help, Add-ins) built from QGIS tools, with all of QGIS's tools and menus within reach, a Project menu and a title row with the search box; reorganised panes (Contents with List By views, Catalog, Geoprocessing, Symbology); view tabs that show one map view at a time with its own layers and extent; a map status bar with typed coordinates (DD, DMS, DDM, MGRS, USNG, UTM, linear units); a gallery of open basemaps that need no API key; an attribute table toolbar and footer; default symbology, cyan selection, label font and 14 colour ramps; and light, flat icons for all of QGIS. English and Polish. Switching the look off restores QGIS exactly as it was. Not affiliated with or endorsed by Esri; ArcGIS and ArcGIS Pro are trademarks of Esri.

changelog=
    1.0.0 - CyanSkin continues the plugin previously published as ArcSkin: on the first start it takes over that plugin's settings and removes the colour ramps and icon theme it added to QGIS. A new set of 14 colour ramps: terrain, depth, temperature, precipitation, slope, aspect, five single-hue sequential and two diverging ones. Gallery of open basemaps that need no API key. The look stays off after a restart when it was switched off. Typing a scale and pressing Enter no longer shows a Python warning (#5). Switching the look off and on again no longer crashes QGIS with PyQt builds that hand the moved message bar to Python (#4, thanks PawelKra).
